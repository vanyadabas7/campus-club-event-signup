# Campus Club Event Sign-Up

## Project Overview
This is a beginner-friendly Python project that manages registrations for campus club events.

## Features
- Register participants
- Prevent duplicate registrations
- Remove participants
- Display all registered participants
- Check remaining spaces
- Save and load participant information using a text file

## Tools Used
- Python
- Google Colab
- GitHub

## Python Concepts Used
- Variables and data types
- User input and output
- Lists
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Built-in functions such as `print()`, `input()`, and `len()`
- String methods such as `.strip()` and `.lower()`
- File handling using `open()`, `readline()`, and `write()`
- Error handling using `try` and `except`

## How to Use
1. Run the Python program in Google Colab.
2. Enter the event name and maximum capacity.
3. Choose an option from the menu.
4. Register or remove participants.
5. View the participant list and remaining spaces.
6. Save your data before exiting.

## Project Goal
The goal of this project is to practise basic Python programming by creating a simple event registration system.
